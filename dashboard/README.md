# Dashboard de população 60+ por UF

Painel React, TypeScript e Vite que lê `../dados/populacao_60mais_1209.csv` e apresenta totais, gráfico e ranking por UF.

## Executar

Nesta pasta, execute `npm ci` e `npm run dev`. Para o botão de atualização funcionar, prepare o Python e inicie a API seguindo o [README principal](../README.md#api-e-dashboard-opcionais).

## Verificar

- `npm run lint`
- `npm run build`

O build copia o CSV existente naquele momento. Para atualizar os dados pelo robô e visualizá-los imediatamente, use o servidor de desenvolvimento.
